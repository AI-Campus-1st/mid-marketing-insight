# 프로젝트 개요 — 우리가 만드는 것

> 최종 업데이트: 2026-11-15 · 팀원 공유용 요약. 세부 일정은 7일 개발 계획서, 파일 구조는 `PROJECT_STRUCTURE.md` 참고

## 1. 한 줄 요약

**마케팅 산업 뉴스와 DART 공시를 분석해, 광고 경험이 적은 뷰티 브랜드가 어떤 광고 전략을 먼저 검토할지 근거를 갖고 판단하도록 돕는 Streamlit 대시보드**

## 2. 무엇을 만드나

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 뷰티 브랜드를 위한 마케팅 산업 이슈 기반 광고 전략 의사결정 대시보드 |
| 산업군 | 마케팅 (가이드 제공 키워드 5개 사용) |
| 사용자 | 가상 브랜드 **A 뷰티**의 마케팅 담당자 (광고 경험 적음) |
| 핵심 질문 | 마케팅 산업에서 지금 무슨 일이 일어나고 있으며, 우리 브랜드는 어떤 광고 전략을 우선 검토해야 하는가 |
| 결과물 | Streamlit 대시보드, 리포트, 발표 |

**A 뷰티 설정:** 설립 3년 차 인디 색조 브랜드 · 신제품 립틴트 출시 예정 · 올리브영 입점 + 자사몰 · 목적은 신제품 인지도 · 타깃 20대 여성 · 예산 1,000만 원(참고 정보, 배분 계산에는 쓰지 않음)

## 3. 왜 만드나

- **사용자 문제:** 작은 브랜드는 담당자가 한두 명이라 업계 동향을 꾸준히 추적하기 어렵다. "숏폼 해야 한대", "AI로 광고 만든대" 같은 말 중 무엇이 실제 흐름인지 구분할 근거가 없다.
- **주제를 정한 과정:** 처음에는 "광고대행사 매칭"을 기획했다. 강사님 피드백("광고주에게 포트폴리오와 뉴스 중 무엇이 중요한가")을 받고 대행사 포트폴리오를 직접 조사했지만, 공개한 곳이 2~3개사뿐이고 내용도 얕았다. 반면 뉴스·공시는 "어떤 전략이 주목받는가"에 충분히 답할 수 있어서 의사결정을 **"어느 대행사"에서 "어떤 전략"으로** 바꿨다.

## 4. 어떻게 동작하나

```
뉴스 6,469건 ──▶ 관련도 필터(약 1,500건) ──▶ LLM 분류: 관련도 · 전략 테마 · 감성
                                                    │
DART 공시(8개사) ──▶ 사업보고서 근거 추출(언급·계획·실제) ┤
                                                    ▼
                                    테마별 지표 → 전략 카드 → 대시보드
                                                    ▲
                                  A 뷰티 조건(목적·판매 채널) ┘
```

1. **업계 흐름 보기 (뉴스):** 기사를 7개 전략 테마로 나누고, 최근 12개월과 이전 12개월의 비중 변화, 급증 시점, 긍정·부정 비율을 본다.
2. **실체 확인하기 (공시):** 뉴스에서 뜨는 전략을 광고 회사·플랫폼이 실제 사업으로 하고 있는지 사업보고서로 확인한다. 근거 수준은 언급 / 계획 / 실제 투자로 구분한다.
3. **우리 브랜드에 맞추기:** 위 결과에 A 뷰티 조건을 얹어 "먼저 검토할 전략"과 주의할 리스크를 보여준다.

## 5. 전략 테마 7개

| 테마 | 구분 | A 뷰티가 묻는 질문 |
|---|---|---|
| 숏폼·영상 광고 | 기회 | 릴스·쇼츠에 예산을 써야 하나 |
| 인플루언서·SNS | 기회 | 신제품 인지도에 인플루언서가 효과적인가 |
| 리테일미디어·커머스 광고 | 기회 | 올리브영·쿠팡 같은 판매처 광고가 뜨고 있나 |
| 검색광고 | 기회 | 자사몰 유입에 검색광고가 여전히 유효한가 |
| AI 광고 자동화·생성형 AI 소재 | 기회 | 적은 인력으로 AI 도구를 써도 되나 |
| 옥외·디지털 옥외(DOOH) | 기회 | 지하철·전광판 광고는 어떤 흐름인가 |
| 개인정보·쿠키 규제 | **리스크** | 타깃 광고에서 무엇을 조심해야 하나 |

규제는 점수에 넣지 않고 분기별 리스크 타임라인으로 따로 보여준다. 테마 목록은 Day 3 EDA 후 확정한다.

## 7. 대시보드 구성 (초안)

- **상단 결론 카드:** "우선 검토할 전략"과 리스크 + 한계 문구
- **공통 필터:** 기간 · 기업 · 테마 (모든 차트에 반영)
- **탭 1 산업 이슈:** 분기별 기사 추이, 급증 시점, 테마 비중
- **탭 2 전략 테마 비교:** 테마별 비중 변화·감성·공시 근거, 표본 부족 표시
- **탭 3 공시 Q&A (RAG):** 공시명·제출일·DART 링크 표시, 근거 없으면 거절
- **탭 4 A 뷰티 전략 카드:** 브랜드 조건에 맞는 전략, 규제 리스크 타임라인

## 8. 하지 않는 것 (한계)

- 광고 효과·성과를 예측하지 않는다. (광고 성과 데이터가 없음)
- 예산을 얼마씩 배분할지 계산하지 않는다. (매체 단가·효과 데이터가 없음)
- 대행사를 추천하지 않는다. (공개 포트폴리오 부족)
- 공시의 "사업 언급"을 "실제 투자"로 해석하지 않는다.

결론 카드 아래 고정 문구: *이 결과는 뉴스·공시 기반 산업 동향이며 광고 성과를 예측하지 않습니다. 기사 수는 수집 키워드에 따라 차이가 있습니다.*

# 대시보드 디자인 레퍼런스

Streamlit 화면(`dashboard/`) 디자인을 고칠 때 참고할 자료를 두는 곳.

## 넣는 것
- 참고할 대시보드·서비스 화면 캡처 (`.png` `.jpg` `.webp` `.gif`), PDF
- 파일 이름에 무엇을 참고하는지 적기 — 예: `01_상단결론카드_레이아웃.png`, `02_사이드바_필터.png`, `03_차트_색감.png`
- 출처(서비스 이름·URL)와 참고할 점은 아래 표에 한 줄씩

## 저장소에는 안 올라감
이 폴더의 이미지·PDF 는 `.gitignore` 로 제외돼요 (남의 화면 캡처라 저작권이 있을 수 있음). 이 README 만 올라가요.
팀원과 같이 보려면 파일은 따로 공유하고, 아래 표만 저장소로 맞춰요.
